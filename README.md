# VPf09 - AI-бот ВКонтакте

Бот отвечает на личные сообщения сообщества ВКонтакте с помощью языковой модели
через ProxyAPI. Он получает события через VKBottle LongPoll и сохраняет диалоги
в JSON. Проект выполнен как базовое задание урока VPf09.

## Возможности

- Главное меню: новый диалог, список диалогов, смена режима, настройки, помощь.
- Роли: обычный помощник, программист, преподаватель, бизнес-консультант,
  дружелюбный собеседник. При смене роли контекст текущего диалога сохраняется.
- Переключение, переименование и удаление диалогов; очистка текущей истории.
- Отдельный `users/<vk_user_id>.json` на пользователя. В каждом диалоге сохраняются
  последние 100 реплик с ролями и временем; данные доступны после перезапуска.
- В настройках видны модель и фактические счётчики токенов из ответов ProxyAPI.

## Что понадобится

- macOS или Linux и Python 3 версии 3.10 или новее. Проект проверен на Python 3.13;
  нативный запуск на Windows не поддерживается.
- Сообщество ВКонтакте, которым вы управляете, и его ключ доступа с правом
  работы с сообщениями. Включите сообщения сообщества, возможности ботов,
  LongPoll API и событие входящего сообщения.
- Ключ ProxyAPI, положительный баланс и доступ к выбранной модели. По умолчанию
  используется `openai/gpt-6-luna`.

## Установка и запуск

Клонируйте репозиторий и выполняйте команды из папки проекта:

```bash
git clone https://github.com/vtaranov/zerocoder-vpf09-vk-ai-bot.git
cd zerocoder-vpf09-vk-ai-bot
```

Создайте виртуальное окружение, установите зависимости и подготовьте настройки:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` в текстовом редакторе и заполните:

- `VK_BOT_TOKEN` - ключ доступа сообщества ВКонтакте.
- `PROXYAPI_KEY` - ключ ProxyAPI.
- `MODEL` - модель ProxyAPI; по умолчанию `openai/gpt-6-luna`.
- `PROXYAPI_BASE_URL` - адрес API; по умолчанию `https://api.proxyapi.ru/v1`.
- `MAX_OUTPUT_TOKENS` - ограничение ответа модели; по умолчанию `800`.

Если одноимённые переменные уже заданы в окружении, они имеют приоритет над
значениями из `.env`.

Запустите бота:

```bash
.venv/bin/python bot.py
```

Когда в журнале появится «LongPoll отвечает корректно», откройте сообщения
сообщества от своего личного профиля и отправьте `Начать`. Бот покажет меню.
Оставьте процесс запущенным для получения сообщений; для остановки нажмите Ctrl+C
в терминале. Не запускайте одновременно два бота с одним токеном сообщества.

Для проверки памяти создайте диалог, сообщите боту любое кодовое слово и спросите
его следующим сообщением. Кнопка «Сменить режим» меняет роль текущего диалога,
а «Список диалогов» позволяет вернуться к предыдущим беседам. В настройках
доступны переименование, очистка истории и удаление. Команда `Меню` отменяет
ввод названия.

## Проверка

Автономные тесты работают без запросов к внешним API:

```bash
.venv/bin/python -m unittest -v test_bot
```

Для дополнительной проверки модели и памяти можно выполнить:

```bash
.venv/bin/python check_live.py
```

Скрипт делает до шести платных запросов к ProxyAPI, проверяет ответы и сохраняет
протокол в `artifacts/proxyapi-live-check.json` внутри проекта. Он читает оба
ключа из общей конфигурации `.env`, но запросы к VK не отправляет. Сам VK-бот
проверяется перепиской с сообществом.

При ошибке VK `29 - Rate limit reached` бот пишет в журнал, что LongPoll
недоступен, и ждёт 300 секунд до следующей попытки. При обычной сетевой ошибке -
30 секунд. Запись о старте процесса сама по себе не подтверждает приём сообщений:
в журнале должна появиться строка «LongPoll отвечает корректно».
Если сервер отклоняет полученную сессию (`failed: 2`), обновление также выполняется
с паузой 300 секунд, чтобы не исчерпать лимит запросами по кругу.

## Хранение данных

История каждого пользователя сохраняется в `users/<vk_user_id>.json` внутри
проекта. При запуске из папки проекта состояние LongPoll находится в `.vkbottle/`.
Эти папки, `artifacts/`, `.env` и `.venv/` исключены из Git.
Текст вопроса и контекст активного диалога отправляются через ProxyAPI выбранной
модели. Бот обрабатывает личные сообщения всех пользователей, которые пишут
сообществу.
